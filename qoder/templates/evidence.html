如何核对

评审指引
  1. 在“资料库”搜索任意知识点，记下 query_id；在上方查询记录中找到同一条，核对 SQL 中的 MATCH ... AGAINST、参数、返回行数和相关度。
  2. 完成一轮复习并故意答错一题；在“教练记忆”页看到 weak_point 记忆；答错后的解析会带上 seekdb 检索出的原文片段。
  3. 重启应用或执行 python -m wengu pc restart；再开始新一轮，答题页的计划影响区会引用重启前写入的记忆。
  4. 上述过程也会写入 docs/runs/db_queries.jsonl、docs/runs/powercontext_memory.jsonl、docs/runs/coach_plans.jsonl 和 docs/runs/powercontext_restart.jsonl。
